## Overview
This repository contains the implementation for Assignment 2.

## Running the Notebook

1. Clone the repository
    git clone https://github.com/davidjwilliams03/COMP3610-Big-Data-Analytics-Assignment-2-ML-Model-Training-Evaluation.git

3. Launch Jupyter
